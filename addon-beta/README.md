# Quotinator (BETA)

The beta channel of Quotinator — a self-hosted quote REST API. Serves real, verified quotes from films, books, television, and famous people — no AI-generated quotes.

This is the same software as the stable **Quotinator** add-on, published from the same repository. It tracks pre-release versions so you can try upcoming changes before they reach the stable channel — install both side by side, or this one alone if you want to stay on the beta track.

## Features

- REST API with random, search, paginated, and lookup endpoints
- 780 curated quotes seeded from MIT-licensed sources
- Optional language parameter — returns translated quote when available, falls back to original
- Multi-arch image (amd64 + aarch64)

## Usage

After installation, Quotinator (BETA) appears in the Home Assistant sidebar. Open it from there, or see the **Documentation** tab for API endpoints and configuration options — identical to the stable add-on's, since it's the same application.

> **Note:** a beta version may contain unreleased or not-yet-fully-verified changes. If you hit an issue, please report it against the version shown in this add-on's info panel.
